# Avatar Engine (ТЗ §7–§9)

## Режимы

| Режим | Уровень | Описание |
|-------|---------|----------|
| Living Orb | 0 | Световой шар — базовый режим, работает везде |
| Light Avatar | 1 | Лёгкий аватар |
| Realistic Avatar | 2 | Реалистичный аватар |
| Full Real Avatar | 3 | Полноценный реальный аватар |

## REAL SVETLANA (ТЗ §8)

Если устройство достаточно мощное **либо** доступен мощный удалённый
compute, Светлана может перейти из Orb в Real Avatar.

Требования: реалистичный, естественный, взрослый, естественная мимика,
синхронизация речи и губ; **без** anime, без plastic look, без
cyberpunk, без чрезмерной сексуализации.

## Автоматический выбор

`AvatarEngine.evaluate()` выбирает уровень по реальным ресурсам:

- FPS (измеряется в UI);
- CPU (ядра);
- GPU;
- RAM;
- thermal state;
- battery;
- latency;
- local inference available;
- remote inference available;
- network.

## Деградация

Если Real Avatar работает плохо:

```
Real Avatar → Light Avatar → Living Orb
```

`AvatarEngine.degrade()` понижает уровень на один при просадке FPS.

## Реализация в проекте

- `LivingOrb` (Compose Canvas) — пульсирующий стеклянный шар с
  жидким светом и лёгкими частицами. Без тяжёлой 3D-графики,
  без WebGL/Three.js.
- Уровни 1–3 добавляют орбитальные кольца и расходящееся свечение.
- Рендеринг реалистичного аватара — это отдельный движок, который
  подключается при наличии ресурсов (и соблюдает правило
  «предложить → решение пользователя → скачать»).

## Стиль

Premium AI / Dark Glass / Liquid Light: почти чёрный фон, мягкий
mint/green, минимализм, жидкий свет, лёгкие частицы, аккуратные
анимации. Без anime, cyberpunk, кислотного neon, дешёвого sci-fi,
тяжёлой 3D-графики.
