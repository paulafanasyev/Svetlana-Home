# Переводчик RU ↔ VI

`TranslatorActivity` и `RuViTranslator` дают отдельный переводчик русского и вьетнамского.

## Режимы

- RU → VI
- VI → RU
- текстовый ввод
- голосовой ввод с on-device `SpeechRecognizer`
- озвучивание результата через системный Android TTS с целевой locale

## Приватность

Translation использует ML Kit Translation. Модель скачивается только после явного нажатия «Скачать модель» и по умолчанию только по Wi‑Fi. После загрузки перевод выполняется на устройстве; `translate()` сам модель не скачивает.

Голосовой режим дополнительно требует доступный on-device STT. Если Android не предоставляет on-device распознаватель, приложение не запускает голосовой перевод, чтобы не выдавать сетевое STT за offline.

## Ограничения

Это пошаговый перевод текста/голоса, а не непрерывный двусторонний разговор в фоне. Фактический перевод на физическом устройстве пока требует acceptance-теста.

## Статус

- CODE VERIFIED: экран, направления, явная загрузка модели и локальный post-download translation path.
- NOT PROVEN: фактический RU↔VI inference и качество TTS/STT на Poco X3 NFC.
