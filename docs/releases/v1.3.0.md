# Svetlana Home v1.3.0

## Новое
- **Английский язык** всего интерфейса: выбор языка при первом запуске и в настройках (Русский / English / как в системе) (#21–#27).
- **Английский голос**: слова пробуждения Sveta/Svetlana, распознавание и озвучка на языке интерфейса, ответы ИИ на английском (#28).
- **Английские команды**: открыть, нажать, ввести, позвонить, написать — с теми же подтверждениями опасных действий (#29, #30).
- **Длинные команды**: «Открой WhatsApp, найди контакт Серый и напиши ему привет», цепочки из 3+ шагов через запятые и «и/потом/затем» (#31).
- **Фоновая загрузка локальной модели** с прогрессом в уведомлении и проверкой после установки (#31).

## Исправлено
- Экран иногда сжимался на 3/4, как будто открыта клавиатура (#31).
- Внешний ИИ «забывался» через ~10 минут и Светлана просила скачать модель (#31).
- Локальная модель не докачивалась, если свернуть окно (#31).
- Отправка в WhatsApp/Telegram: возврат к списку чатов из старого чата, ожидание экранов, имена с «ё» (#33); текст не печатался — вместо поля ввода бралась шапка чата (#34).

## What's new (EN)
- Full English UI and voice (wake words Sveta/Svetlana, STT/TTS in the UI language, English AI replies).
- English and long chained commands (e.g. “open WhatsApp, find the contact John and message him hello”); dangerous actions still need confirmation.
- Local model downloads continue in the background.
- Fixed: phantom keyboard inset (3/4 screen), external AI falling back to local after ~10 min, interrupted model downloads, WhatsApp/Telegram message sending.
