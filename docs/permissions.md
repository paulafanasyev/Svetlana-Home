# Разрешения (ТЗ §25–§28, §59)

## Принцип

Svetlana Home запрашивает только действительно необходимые доступы —
последовательно, в мастере «Настроить Светлану». Ничего лишнего.

## Мастер настройки

Последовательность запросов:

| # | Разрешение | Обязательность | Способ запроса |
|---|------------|----------------|----------------|
| 1 | Микрофон | Требуется | Runtime permission |
| 2 | Камера | Необязательно | Runtime permission |
| 3 | Контакты | Необязательно | Runtime permission |
| 4 | Телефон | Необязательно | Runtime permission |
| 5 | Уведомления | Необязательно | Runtime (Android 13+) |
| 6 | Местоположение | Необязательно | Runtime permission |
| 7 | Hands / Accessibility | Необязательно | Системные настройки |
| 8 | Главный экран | Необязательно | `RoleManager.ROLE_HOME` |

Каждый шаг можно пропустить, если разрешение необязательное.

## Permission Center

«Разрешения Светланы» показывают реальное состояние каждого доступа:

```
Микрофон       ✓ Разрешён
Камера         ✓ Разрешена
Hands          ✓ Активен
Контакты       ✓ Разрешены
Уведомления    ✓ Разрешены
Местоположение ○ Выключено
Home           ✓ Светлана
```

Пользователь может изменить каждое состояние позже — открывается
соответствующий системный экран.

## Постоянные разрешения (ТЗ §26)

Если Android позволяет постоянный доступ и пользователь его разрешил,
Светлана использует его повторно без запроса перед каждой обычной
операцией. Каждое действие не превращается в одноразовое разрешение.

Но если Android требует повторное системное подтверждение — пользователь
проходит штатный flow (ТЗ §26).

## Постоянный доступ ≠ безусловный (ТЗ §59)

Постоянный доступ используется только в пределах разрешённой функции
и Android security model.

## Важное ограничение (ТЗ §28)

Профиль владельца **не является** способом получить:
root, скрытый Accessibility, скрытый микрофон, скрытую камеру,
обход permission, обход системного подтверждения.

Все системные ограничения Android остаются действующими.

## Реализация

- `PermissionManager.list()` — реальные состояния.
- `PermissionManager.settingsIntentFor(key)` — системный экран.
- `PermissionManager.accessibilityEnabled()` — проверка Hands.
- `PermissionManager.isHomeLauncher()` — проверка роли HOME.
- `PermissionSetupScreen` — мастер последовательного запроса.
- `PermissionCenterScreen` — центр разрешений.
