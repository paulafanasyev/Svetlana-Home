# Voice

## Wake words (ТЗ §21)

`Света`, `Светочка`, `Светлана`.

`WakeWordEngine` слушает короткие окна распознавания, и распознанный
текст проверяется на слово пробуждения **полностью локально** — голос
не покидает устройство.

Цикл wake word активен только если пользователь включил его в
настройках и предоставил разрешение на микрофон.

## STT

`SvetlanaSpeechRecognizer` — системный распознаватель Android
(`SpeechRecognizer`) с языком `ru-RU`.

Если на устройстве нет распознавателя (например, без GMS),
приложение честно сообщает «Распознавание речи недоступно» и
продолжает работать через текстовый ввод.

## TTS

`SvetlanaTts` — системный `TextToSpeech` с языком `ru-RU`.
Озвучивает ответы Светланы.

## Архитектура

```
Wake word (Света)
↓
STT (ru-RU)
↓
CommandParser
↓
ActionRouter / AIRouter
↓
Результат
↓
TTS (ru-RU)
```

## Распознаваемые команды (ТЗ §12, §68)

- «Света, открой Telegram.»
- «Света, запусти Mobile Harness.»
- «Света, открой приложение для тестирования.»
- «Света, переключись на Mobile Harness.»
- «Света, вернись назад.»
- «Света, сделай скриншот.»
- «Света, пролистай вниз.»
- «Света, нажми кнопку.»
- «Света, введи это значение.»
- «Света, переведи на вьетнамский.»
- «Света, используй только локальный ИИ.»
- «Света, используй мой сервер.»
- «Света, не отправляй эту информацию в облако.»
- «Света, какой ИИ сейчас отвечает?»
- «Света, какой ИИ может работать на моём телефоне?»

## Диалог

Если команда не является управлением устройством, она уходит в
AI Router (локальная модель / персональный сервер / внешний провайдер)
с учётом персональной памяти (если режим памяти это разрешает).
