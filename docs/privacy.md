# Privacy (ТЗ §41, §49–§51, §61)

## PrivacyRouter / PrivacyPolicy

Решает, можно ли передать конкретный тип данных конкретному бэкенду.

Логика вынесена в чистую функцию `PrivacyPolicy.decide(dataType, backend,
mode, memoryMode)` — единый источник правды, не зависящий от Android.
`PrivacyRouter` делегирует в неё (добавляя чтение режима из настроек),
а `HybridPipeline` вызывает напрямую. Это гарантирует, что LOCAL_ONLY
блокируется одинаково везде — без непредусмотренного fallback.

### Типы данных

`TEXT`, `SCREENSHOT`, `UI_TREE`, `IMAGE`, `AUDIO`, `HISTORY`, `DOCUMENTS`.

### Правила

| Условие | Результат |
|---------|-----------|
| Бэкенд `LOCAL` | Разрешено — данные не покидают устройство |
| Режим `LOCAL_ONLY` | Запрещена любая передача наружу |
| `HISTORY` + внешний AI | Запрещено — память не уходит внешнему AI автоматически |
| `AUDIO`, `SCREENSHOT`, `UI_TREE`, `IMAGE` в режимах `LOCAL_FIRST` / `AUTO` | Тяжёлые данные остаются на устройстве |
| `MY_SERVER` | Данные идут на сервер пользователя |
| `EXTERNAL` | Данные идут выбранному провайдеру |

Покрытие unit-тестами: `PrivacyPolicyTest` (7 сценариев × все типы
данных и режимы) — логика проверяется полностью на JVM.

## Local-Only Mode (ТЗ §50)

В режиме «Только устройство»:
- External AI = запрещён;
- Personal Server = запрещён;
- Cloud = запрещён.

Если локальный ИИ не справляется:

> Для этой задачи нужна более мощная модель, но режим «Только устройство»
> запрещает передачу данных наружу.

## Не переписываем выбор (ТЗ §41)

Если пользователь сказал «Используй только локальный ИИ», Светлана
не переключается на облако из-за ошибки. Она сообщает, что локальная
модель не справилась, и предлагает варианты: другая локальная модель,
мой сервер, внешний AI, отмена.

## PersonalMemory (ТЗ §61)

Режимы: `LOCAL` / `REMOTE` / `DISABLED`.

Персональная память **не отправляется внешнему AI автоматически**.
В режиме `REMOTE` память может идти только на сервер пользователя.

## Внешние провайдеры необязательны (ТЗ §51)

Svetlana Home работает без подключённого внешнего AI:
- базовый launcher — работает;
- Hands — может работать;
- Local AI — опционально;
- External AI — опционально;
- Personal Server — опционально.

## Прозрачность (ТЗ §88)

Пользователь видит: какой провайдер, какая модель, где выполняется
запрос — и может выбрать, сменить, отключить внешнего AI-провайдера
(см. `external-providers.md`).

## Offline (ТЗ §63)

Без интернета работают: launcher, app drawer, app registry, запуск
приложений, базовый Hands, local AI, local STT/TTS, local OCR-чтение
экрана, local translation, настройки.

Облачные функции честно показывают отсутствие сети.
