# Launcher (Главный экран)

## Официальный механизм

Svetlana Home — настоящий Android launcher и поддерживает
официальный механизм `ROLE_HOME` (Android 10+) и
`CATEGORY_HOME` для более старых версий.

- Запрос роли: `RoleManager.createRequestRoleIntent(RoleManager.ROLE_HOME)`
  через `PermissionManager.homeRoleIntent()`.
- Проверка: `RoleManager.isRoleHeld(RoleManager.ROLE_HOME)` (API 29+).
- Запасной путь для API < 29: `Settings.ACTION_HOME_SETTINGS` и
  разрешение `CATEGORY_HOME` в манифесте `HomeActivity`.

## UI-точки назначения (P0 аудита)

1. **Чип на рабочем столе** — если `isRoleHeld(ROLE_HOME)` false, под часами
   показывается «Сделать главным экраном», открывающий системный диалог ROLE_HOME.
   Статус перепроверяется при каждом возврате (ON_RESUME).
2. **Настройки → Главный экран** — отдельный раздел с кнопкой
   «Сделать Светланой главным экраном».

## Рабочий стол — как у стандартного Android launcher

`LauncherScreen` (см. `ui/launcher/LauncherScreen.kt`):

- **Системные обои**: тема `Theme.SvetlanaHome.Launcher` (`windowShowWallpaper`,
  прозрачный фон) + `FLAG_SHOW_WALLPAPER`. Сверху и снизу мягкое затемнение,
  чтобы белые подписи читались на любых обоях.
- **Виджет часов**: время, дата по-русски и чип «Светлана: …» с последним ответом
  (касание — окно чата).
- **Сетка иконок 4×4**: закреплённые приложения. Пока ничего не закреплено,
  показываются подсказки (недавние + популярные), как при первом запуске Pixel.
- **Док**: телефон, сообщения, браузер, камера — по приложениям по умолчанию
  (`DefaultApps`, официальные Intent'ы), без подписей.
- **Строка поиска**: «Поиск или вопрос Светлане», орб — чат, микрофон — голос.
- **Жесты**: свайп вверх — все приложения; свайп вниз — шторка уведомлений;
  долгое нажатие на пустом месте — меню «Обои и стиль / Приложения / Настройки»;
  долгое нажатие на иконке — «На главный экран / Убрать», «О приложении», «Удалить».
- **Кнопка «Домой»** при открытом launcher закрывает окна и возвращает на рабочий стол.

## Все приложения (свайп вверх)

Поиск сверху, «Недавние», затем алфавитная сетка (русская сортировка, `Collator`).
Если приложение не найдено — «Спросить Светлану: «…»». Закрывается свайпом вниз
от верха списка, свайпом по заголовку или «Назад».

## Функции Светланы — в дополнительных окнах

- **Панель Светланы** — свайп вправо с рабочего стола (как экран −1 у Pixel):
  орб, последний ответ, «Сказать» / «Написать» и плитки: Чат, Голос,
  Переводчик, История, Настройки, Приложения.
- **Окно «Чат»** — полная переписка (`ChatScreen`).
- **Окно «Голос»** — орб, ответ, подтверждение опасных действий.
- **Окно «Поиск»** — приложения, «Спросить Светлану», «Искать в интернете».

Чистая логика раскладки (док, сетка, поиск, сортировка) — в `LauncherModel`
и покрыта unit-тестами `LauncherModelTest`.

## Скриншоты

`LauncherScreenshotDeviceTest` снимает реальные экраны на CI-эмуляторе
(рабочий стол, все приложения, меню, панель, чат, голос, поиск).
`scripts/run_instrumentation.sh` забирает снимки, распознаёт текст (OCR)
и публикует ссылки в аннотациях проверки «Instrumentation tests».

## Поведение после перезагрузки

`BootCompletedReceiver` принимает `BOOT_COMPLETED` /
`LOCKED_BOOT_COMPLETED`. Launcher остаётся главным экраном после
перезагрузки (роль хранится системой). Сервис Hands не запускается
автоматически — пользователь включает его сам в системных настройках.

## Onboarding при первом запуске (ТЗ §65)

- `HomeScreen` проверяет `settings.onboardingDone` при старте.
- Если onboarding не пройден — показывается `OnboardingFlowContent`
  (приветствие → профиль владельца → разрешения) на непрозрачном фоне.
- По завершении — рабочий стол.
